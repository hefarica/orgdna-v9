APP WEB LOCAL, CON EXCEL COMO COMPLEMENTO
1. Descomprime todo el ZIP conservando carpetas.
2. En Windows con Python 3.10+ ya instalado, ejecuta launch.cmd para abrir la aplicación local. En otro sistema, python -m engine.bridge inicia el panel; la integración Excel COM requiere Windows y Excel. No se instala software automáticamente.
3. Trabaja desde el panel local: configura el proyecto, genera/revisa la organización y utiliza sus exportaciones Recipe, Definitions Backup y paquete ZIP. La aplicación no exige abrir Excel para generar una organización.
4. Si quieres usar el complemento Excel, abre ADN_Organizacional.xlsx y selecciónalo en el panel. Es una plantilla inicial del paquete, no una copia de tu libro abierto ni una prueba de que sus celdas estén sincronizadas con los JSON actuales. Aplicar al libro es una acción explícita.
5. Las descargas contienen el estado actual de organización del panel; un GET no guarda Excel ni consulta proveedores. Los enlaces de Exportacion en Excel también abren Recipe, Definitions Backup y ZIP en el motor local. Exportar o descargar no llama a proveedores ni lanza Council. La generación mediante IA requiere el flujo API autorizado; la plantilla offline no realiza llamadas ni acredita un diseño de IA.
